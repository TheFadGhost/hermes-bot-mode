# Everyday jobs for Chief

Start in Chief's chat. Say what result you need, the date range and any limits. Connect a service from **Settings → Connections** when prompted. Review any proposed external action before approving it.

Try:

- “Check stock against recent sales and draft next week's reorder list. Separate unpaid orders and leave out discontinued products.”
- “Find orders that still need dispatch. Group the exceptions so I can deal with them first.”
- “Draft a short reply to this customer in my usual tone. Keep the order details accurate and let me review it.”
- “Compare this month's sales and supplier costs with last month. Show where any numbers are missing.”
- “Prepare tomorrow's briefing: urgent customer messages, delayed orders and stock running low.”
- “Create a research helper for this supplier comparison. Ask it to report back here with sources.”

## Small controls

**+ or /** opens Connections, Private input, Teach a task and other actions. The microphone records a short note, sends audio for transcription through OpenRouter/Microsoft, then lets you review the text before inserting it. Nothing is automatically sent as a chat message.

**Show details** opens longer descriptions; **Hide details** keeps them collapsed on this browser until you reopen them. Live requests that need your decision remain visible.

**Private input** stores a labelled value outside the chat and model context. Chief sees a reference. You review the service and action before that service receives the value. For browser passwords, take control of the private computer and sign in directly.

**Teach a task** saves reviewed steps and optional selected screen stills. Run a test, inspect the result and mark it verified only when it worked. Edit, pause or remove procedures later in Settings.

## Moving between Telegram and Bot Mode

Telegram can use `bot_mode` to create helpers, start work and retrieve results. Ask for the job's result when you return. Shared facts are refreshed periodically and on demand. The original Telegram conversation archive is imported into Chief's continuing chat and remains searchable. Bot Mode's visible chats are searchable from Telegram with `bot_mode_history`.

Private bot memories and protected input values are not copied into Telegram's shared memory. Older history is retrieved when needed; no system can promise perfect recall, so ask Chief to find the exact earlier message when a detail matters.
